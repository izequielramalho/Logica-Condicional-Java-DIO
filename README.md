# Lógica Condicional e Controle de Fluxos - DIO Orange Tech+

Repositório criado durante o bootcamp Orange Tech+ Backend da DIO,
documentando meu aprendizado sobre lógica condicional e controle 
de fluxos em Java.

## Conteúdo

- **Operadores Relacionais** → comparação entre valores
- **Operadores Lógicos** → combinação de condições
- **Controle de Fluxo** → if, else, switch
- **Blocos** → estrutura e organização de blocos de código

## Tecnologias
- Java 17
- IntelliJ IDEA
- Git e GitHub
